# E5: reliance on non-anatomical content (test-time perturbations, unchanged models)

FPDB test (5,271 images). Paired with the unperturbed predictions of the same checkpoint; 95% patient-clustered CIs (B = 2000). Perturbations change only out-of-sector pixels (`a_text`: the UI/text mask; `b_*`: the whole out-of-sector region). Not run (Gate G1): `a_marker/c_control` (Gate G1: caliper detector recall 0.20; 0 detector-and-audit-positive test images); `d_pairs` (Gate G1: 0 caliper pair candidates).
