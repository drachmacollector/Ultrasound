## Finding 2: Dwell Window vs Tier-2 Trigger Metric (Terminology)

  The 'dwell window' (min_dwell_frames / inference_fps) is a STATIC
  parameter-level number â€” how long the smoother holds before switching.

  The Tier-2 gate criterion (docs/instructions/07_STRETCH_GOALS...md)
  requires mean_latency_ms > 400ms measured on GENUINE annotated
  transitions â€” a DYNAMIC measured-behavior metric.  These two numbers
  (571ms dwell window vs Tier-2 400ms gate) are conceptually distinct
  even though they happen to be numerically close.  See Task 11 for
  the full reconciliation table.
